# Abstract

This project developed machine learning models to predict the prices of collectible Pokémon trading cards by analyzing card characteristics and historical price trends. Using data from 381 unique Pokémon cards, four different prediction models—ranging from simple moving averages to advanced algorithms like XGBoost—were built to understand which factors most influence card pricing in a largely unmodeled market. The key discovery was that directly using past prices as predictors created misleading accuracy; instead, the best model focused on honest predictive signals like price momentum (whether prices are trending up or down), price volatility (how much prices fluctuate), and card-specific traits like rarity and character popularity. The XGBoost model achieved realistic predictions with an average error of about $1.88 per card, suggesting that machine learning can meaningfully forecast collectible card values when the right features are chosen. This research demonstrates that alternative assets like trading cards can be effectively modeled using machine learning, opening doors for better pricing tools in niche markets that currently lack sophisticated valuation methods.
